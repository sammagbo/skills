## Français

Ce dossier a été produit par Bastão v0.1.0 sur le dépôt fictif `skills/bastao/tests/fixtures/estante` (le système de prêt de livres d'une école imaginaire). Le développeur qui part était joué par un second agent, qui répondait aux questions à partir d'une liste de faits écrite à l'avance (`skills/bastao/tests/cases/estante/verdade.md`).

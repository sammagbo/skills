# Jargão → linguagem corrente (FR e PT)

Regra: na primeira vez que um termo técnico aparece num documento, ele vem traduzido entre parênteses ou substituído pela expressão corrente. Nos documentos 1, 4 e 6, usar só a expressão corrente. O nome próprio de um produto (Docker, Postgres, HikCentral) pode ficar, acompanhado do que ele faz.

| Termo | Français | Português |
|---|---|---|
| backend | le programme qui tourne sur le serveur | o programa que roda no servidor |
| frontend / interface | l'écran que les gens utilisent | a tela que as pessoas usam |
| serveur / VM | la machine, chez {{hébergeur}}, où le programme tourne | a máquina, em {{provedor}}, onde o programa roda |
| conteneur / Docker | la boîte dans laquelle le programme tourne, qui redémarre d'un bloc | a caixa dentro da qual o programa roda, que reinicia de uma vez |
| base de données | l'endroit où les informations sont enregistrées | o lugar onde as informações ficam gravadas |
| API | la porte par laquelle d'autres programmes lui parlent | a porta pela qual outros programas falam com ele |
| webhook | le message que l'équipement envoie au programme à chaque passage | a mensagem que o equipamento manda ao programa a cada passagem |
| déploiement / deploy | installer une nouvelle version sur la machine | instalar uma nova versão na máquina |
| migration (base) | mise à jour de la façon dont les informations sont rangées ; se fait avec la nouvelle version | atualização da forma como as informações são organizadas; vem junto com a nova versão |
| rollback | revenir à la version précédente | voltar para a versão anterior |
| sauvegarde / backup | copie des informations, pour les retrouver si la machine casse | cópia das informações, para recuperar se a máquina quebrar |
| restauration | remettre les informations d'une copie à la place des actuelles | recolocar as informações de uma cópia no lugar das atuais |
| journal / log | les messages que le programme écrit sur ce qu'il fait | as mensagens que o programa escreve sobre o que faz |
| healthcheck | le signe « je vais bien » que le programme donne | o sinal «estou bem» que o programa dá |
| variable d'environnement | un réglage lu au démarrage (nom seulement ; la valeur est gardée ailleurs) | um ajuste lido na inicialização (só o nome; o valor fica guardado em outro lugar) |
| certificat (HTTPS) | la pièce qui fait apparaître le cadenas dans le navigateur ; elle expire | a peça que faz aparecer o cadeado no navegador; ela vence |
| nom de domaine | l'adresse du site, louée chaque année | o endereço do site, alugado todo ano |
| licence | l'autorisation d'utiliser le programme, avec une date de fin | a autorização de usar o programa, com data de fim |
| jeton / token | un mot de passe long réservé aux programmes | uma senha longa reservada aos programas |
| SSH | la connexion technique à la machine, réservée au référent | a conexão técnica à máquina, reservada à referência técnica |
| cron / tâche planifiée | ce que la machine fait toute seule à heure fixe | o que a máquina faz sozinha em hora marcada |
| dépôt / repo | l'endroit où le code source est gardé et versionné | o lugar onde o código-fonte fica guardado e versionado |
| commit / version | l'état précis du code à une date | o estado exato do código em uma data |
| fuseau horaire (serveur) | l'heure de la machine, qui peut différer de l'heure du mur | a hora da máquina, que pode ser diferente da hora da parede |
